# 1次元セルオートマトン Rule 110 チューリング完全可視化

Wolfram 1次元セルオートマトン（Rule 0〜255）の時間発展をキャンバス上に描画するビジュアライザ。各世代を縦方向に積み重ね、全256通りのルールを即座に切り替えて比較できる。Rule 110はチューリング完全であり複雑な自己組織化パターンを、Rule 30はカオス的な模様を、Rule 90はシェルピンスキー三角形を生成する。初期条件（中央1セル or ランダム）やセルサイズも変更可能で、ルール遷移表も同時表示される。

## 使い方

スライダーでルール番号を選ぶか「Rule 110」「Rule 30」ボタンを押すと即座に描画される。「1世代進む」ボタンでステップ実行も可能。
